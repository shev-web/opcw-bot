Политика конфиденциальности OPCW Bot

OPCW Bot это личный помощник одного владельца. Доступ к Google Календарю (право calendar.events) используется только для того, чтобы по просьбе владельца показывать и создавать события в его собственном календаре.

  • Данные календаря не передаются третьим лицам, не продаются и не используются для рекламы или обучения моделей.
  • Ключ доступа хранится на сервере владельца; отозвать доступ можно в любой момент на странице myaccount.google.com/permissions.
  • Другие пользователи приложением не пользуются, их данные не собираются.

Использование данных, полученных из Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Privacy policy (English)

OPCW Bot is a personal assistant for a single owner. Google Calendar access (calendar.events) is used only to show and create events in the owner's own calendar at the owner's request. Data is not shared, sold, or used for advertising or model training. The owner can revoke access at any time at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
